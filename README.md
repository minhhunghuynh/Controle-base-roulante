# Contrôle de base roulante — ELEC-H-309

Projet réalisé dans le cadre du cours ELEC-H-309 (ULB).
L'objectif est de contrôler une base roulante (voiture à deux roues) à l'aide d'un microcontrôleur, en lui faisant suivre des trajectoires définies par des commandes sonores.

## Structure du dépôt

| Dossier / Fichier | Description |
|---|---|
| `code/` | Code source du microcontrôleur (déplacement, ADC, code final) |
| `Circuit/` | Schémas et informations sur le circuit électronique |
| `Donnee_experimentales.xlsx` | Données collectées lors des expériences |
| `executive_summary_Aouaras_De...` | Résumé exécutif du projet |
| `notion.png` | Capture du tableau Notion utilisé pour l'organisation |

## Organisation

Le projet a été organisé via Notion, permettant de lister et d'attribuer les tâches à chaque membre, tout en visualisant l'avancement sous forme de ligne du temps.

# Ligne droite
## Description

Code essayant de faire avancer la voiture d'une distance prédeterminée.
Divisé en quatre étapes :
- Correction via boucle de rétroaction
- Accéleration
- Maintien de la vitesse
- Décélération


# Tournant 
## Description
Codes faisant tourner la voiture 

# Sauvagarde_m
## Descrpition 
- Fichier de sauvegarde des version non abouties et mélangées.
- "commande_de_la_voiture" contient le code pour entièreté de la base roulante aboutie

# ADC
## Description 
Fonctionnalités pour permettre l'échantillonage, la corrélation et la traduction des signaux pour décoder les instructions sonores.

# Code_complet
## Description
Mise en commun du code avec ADC et du code avec base roulante fonctionnelle mais avec déviation importante d'une trajectoire rectiligne.

# Code_final
## Description
Code presenté lors de l'évaluation finale.
Basé sur la V5 du fichier "Code_complet" et ajoute la prise en compte de la taille différente des deux roues.
